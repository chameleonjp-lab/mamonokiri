## 実機確認の保留項目

以下は自動検査で代替できないため、現時点ではすべて**未確認**である。

- iPhone 17 Pro Safariの標準設定で、縦・横、Dynamic Island/safe-area、Safari上部・下部バー、タイトルのスクロール、名前入力後の開始。
- 2本指、長押し、高速タップ、同時操作、画面を離れて戻る、戻る確認、ミュート、読み上げ、低描画設定、閉じて再開。

- Safariのバックグラウンド復帰後、停止前の攻撃・飛刃・連撃が勝手に進まず、再開猶予後に一度だけ続くこと。

NullEngine・Happy DOM・静的契約検査の成功は、これらの実機条件の確認済みを意味しない。

## 本番依存と公開ゲート

Supabase migration `20260911000000_mamonokiri_scoped_ranking.sql` はリポジトリに含まれるが、本番適用と専用RPCの実データ確認は未完了である。送信失敗を表示できるため未適用でもゲームは続くが、オンラインランキングを公開機能として告知する前に、適用・条件分離・同じ勝負IDの重複防止を確認する。

公開へ進める条件は次の4つ。

1. 上記5コマンドがすべて成功し、大きなチャンク警告を既知の残課題として受け入れる。
2. iPhone 17 Pro Safariの実機記録を追加し、未確認項目を残さない（再現できない項目は理由と代替計測を記録する）。
3. Supabase本番migrationとRPCを適用し、モード・難易度・得点規則・勝負IDの分離を実データで確認する。
4. 実機記録と自動証跡を別の確認者が読み、公開可の判断を明示する。

このPRでは1〜4を完了していないため、公開判断は保留である。
