# マモノキリ

## どんなゲーム？

敵の攻撃予告を見て、左右へ避けるか防御するかを選び、斬撃と反撃で50体の魔物を倒していくアクションゲームです。素早く押し続けるだけでなく、敵ごとの予告を読み、攻めるタイミングを選ぶ遊びです。

## はじめの一戦

1. 名前を入力して「新しく始める」を選びます。最初の難易度はイージーです。
2. 敵の予告を見ながら、画面に案内された移動・斬撃・防御を使います。スマートフォンはタッチ、PCはキーボード操作の案内を表示します。
3. 正式勝負は50体の連戦です。まず操作を試したい場合は「稽古を試す」で最初の3体を安全に練習できます。

稽古は記録やランキングの対象外で、正式勝負に不利を持ち越しません。正式勝負の結果では失敗理由や次に試す行動を確認し、再挑戦できます。
